# COO Prep — правила для Claude

Статическое PWA-приложение для подготовки к интервью (без сборки). Сайт: https://dika-nurut.github.io/coo-prep/ — GitHub Pages публикует ветку `main` из корня автоматически (1–2 минуты после пуша).

## Выкладка: владелец разрешает пушить в `main` самостоятельно

После каждого законченного изменения выкладывай его в `main` без отдельного вопроса, строго в таком порядке:

1. `git fetch origin main` и влей `origin/main` в рабочую ветку. В `main` пишут и другие сессии — при конфликте сохраняй обе стороны, ничего из `main` не выбрасывай.
2. Проверь:
   - банк задач грузится в Node (подгрузи `bank.js`, `expansion.js`, `knowledge.js`, `sprint.js`, `hft.js`, `teach.js`, `tools.js`, `hard.js`, `base.js` в фейковый `window`): нет дублей `id`, у `num` есть число `a`, у `mc` корректный `correct`, в текстах нет `NaN`/`undefined`;
   - интерфейс открывается в Chromium без ошибок в консоли (локальный `python3 -m http.server`).
3. Если менялся JS/HTML — подними `?v=` у изменённого файла в `index.html` и в `ASSETS` в `sw.js`, и номер `CACHE` в `sw.js`.
4. Закоммить, запушь рабочую ветку, затем `git push origin HEAD:main`. Только fast-forward: никогда `--force` и не переписывай историю `main`.
5. Дождись публикации и сверь файлы сайта с запушенными (`curl` + `sha1sum`). Сообщи пользователю результат.

## Структура

- `index.html` — весь UI и логика (состояние в `localStorage`, ключ `cooprep.v1`).
- `bank.js` — модули и авторские задачи; `expansion.js` — процедурные вариации; `knowledge.js` — объяснения по темам.
- `sprint.js` (модуль S, устный счёт) и `hft.js` (модуль H, HFT-грамотность) — самостоятельные модули: задачи с фиксированным seed (id стабильны), объяснения, хаки, мини-уроки навыков через `window.PREP_EXTRA`.
- `teach.js` (модуль T, нестандартные вопросы CEO и уроки «научи за 5 минут»): утверждённые пользователем сценарии — не переписывай их формулировки без согласования.
- `tools.js` (модуль K, инструменты PM для самого кандидата: закрытие встречи, британский «переводчик», замысел командира, пауза в переговорах, «нет» руководителю, сократовские вопросы, зеркало и сигналы тела, «лети, веди, говори»).
- `hard.js` (модуль Z «Трудные места»: проценты от числа, деление на 25, корни, монеты, Байес — лестница от шага к задаче; также уточняет объяснения приёмов s4_swap, s3_div25, s1_roots, s5_sqrt). Грузится после `sprint.js`.
- `base.js` (модуль O «База счёта»: таблица умножения, десятки × однозначное, удвоение и половина, двузначное × однозначное, «рядом с круглым»; задачи перечисляются детерминированно). Грузится после `hard.js`, стоит первым во вкладке «Цифры».
- Не меняй генераторы так, чтобы менялись `id` уже существующих задач — у пользователя пропадёт прогресс.
